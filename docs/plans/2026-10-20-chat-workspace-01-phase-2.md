# Chat Workspace 01 第二期：资源级精细操作

日期：2026-10-20。基于已合入 main 的第一期和本地 session title / Sidebar 图标调整实现。此次只实现本地改动，不创建提交或推送。

后续 review 修正、最终范围及提交顺序以 [第二期 review 与 commit 计划](2026-10-20-chat-workspace-01-phase-2-review-commit-plan.md) 为准；下方验证数量记录的是第二期初始实现快照。

## 已实现

- 文件级接受／拒绝，沿用 `onReview(resource, decision)` 的具体版本回调。保存期间锁定重复操作，仍可浏览其他内容；由宿主确认结果，不虚构成功状态。
- 单一底部审阅区：待审阅列表、前后循环跳转、当前文件操作；批量接受／拒绝收入更多菜单。只导航就绪的待审阅项。失败标明文件，重试一个文件不清除其他失败记录，新版本不继承旧版本错误。
- 标签更多菜单列出全部打开资源，并提供关闭其他／全部标签。新增可选 `onCloseMany(resources)`，提供时所有关闭通过它原子处理；否则兼容逐项 `onClose`。关闭不代表完成审阅，完整资源目录及计数仍由宿主持有。
- 图片原始尺寸、绝对比例缩放及鼠标拖动平移。手动比例不随容器宽度变化；适应窗口模式跟随容器。触屏和键盘保留原生滚动；取消拖动释放内部状态。
- 保持 32px 操作按钮、Alert 信息色、xl 圆角和 p-3 外间距。底部按可用面板宽度换行，避免桌面窄分栏中提示和按钮重叠。双语文档、Agent 指南和生成产物同步。

## 明确边界

不实现 Diff 按变更块审阅、行级评论或代码编辑。不修改磁盘文件，不连接真实模型或文件保存服务，不新增包依赖。ArtifactPanel 继续独立使用，ChatWorkspace 继续复用 ChatThread。
