| Dropdown / MenuItem | 修复键盘激活只关闭菜单、未执行消费者动作的问题；将动作传给 primitive 的事件入口，鼠标、Enter、空格各执行一次 | 菜单原有定位、焦点、关闭和视觉实现保持；没有页面名称专用参数 |

两处列表新增可选 `state`、`refreshing`、`retainDataOnError`、`statusMessage`、`onRetry`；默认行为保持。原 `onRefresh: () => void` 类型保留，接受原有返回任意值的回调，也可以接受 async 函数；运行时等待其实际返回值并阻止重复请求。没有合并领域枚举，没有新增全局请求引擎。

首次加载占据内容区域，首次失败采用 ErrorState；已有数据的刷新失败采用局部 InlineNotice，不盖住列表或图表。静态状态默认不建立错误 live region；新发生的回调拒绝只在一处宣告。数据新鲜度与刷新活动可以同时显示，因为它们表达不同事实。

原健康状态、风险等级、容量及阶段二确认的主题蓝色保持各自含义。页面/面板/图表继续由现有 PageLayout、Card、Container 和 Chart 组合拥有表面层级，没有新增同义面板或样式框架。

## 2 人工验收页面与步骤

四页均有“演示数据设置”图标按钮。文档预览中位于“预览 / 代码”右侧，独立 / 全屏预览中为可拖拽、距边缘 16px 的 Neutral 悬浮按钮；菜单内直接选择模拟数据状态，并用 Switch 独立开启“下次刷新失败”。后者通过实际拒绝的 Promise 验证异常，而不是只切换错误标题。菜单调整的验收记录见 [演示数据设置工具栏](./2026-10-06-demo-settings-toolbar.md)。

| 页面 | 验收路径 | 具体操作与预期 |
| --- | --- | --- |
| [Project Monitor](http://localhost:3007/zh-CN/block-demo/project-monitor-01) | 概览 → 报告 → 改时间范围 → 存储 → 概览 | “报告”切换 60 分钟/6 小时/24 小时，图形、数据表和请求统计一起更新；返回概览后保留选择。存储显示相同快照的已用/剩余量。复制项目地址得到明确反馈，自定义开关仍可操作 |
| [AI Gateway Overview](http://localhost:3007/zh-CN/block-demo/ai-gateway-overview-01) | 改窗口 → 请求/费用/延迟 → 提供商详情 → 刷新/失败重试 | 1d/7d/30d/90d 改变实际数据和日期；展开数据表核对单位。提供商图例打开对应提供商详情，Escape 关闭后返回触发项。窗口与系列颜色不因刷新或重试重置 |
| [Cluster Environment List](http://localhost:3007/zh-CN/block-demo/cluster-environment-list-01) | 健康/过期筛选 → 搜索 → 清空 → 组织切换 → 详情 → 导航折叠 | “数据过期”显示健康仍为正常的旧快照，不能变成资源告警。搜索无结果有清空入口。组织菜单通过鼠标或 Enter 切换名称并关闭；详情收到对应环境。手机展开操作导航后可 Escape 关闭并返回按钮 |
| [Monitoring Alert List](http://localhost:3007/zh-CN/block-demo/monitoring-alert-list-01) | 严重程度/环境筛选 → 分页 → 记录 → 处置/静音/分析 | 默认示例 8 条、每页 5 条；P0 筛选保留 3 条。键盘打开已处置记录，处置待处理行后出现新记录且 P0 等级不变。“不再提醒”移除指定行；末页三行逐一静音后回到第 1 页、共 5 条。AI 入口明确显示示例分析，关闭后焦点返回 |

四页共用异常路径：

1. 选择“首次加载”：显示骨架，不能同时出现失败或确认无数据。
2. 选择“首次失败”：显示一处 ErrorState 和重试入口，不展示成功数据。点击重试后恢复。
3. 选择“后台刷新”或“数据过期并刷新”：旧数据仍可读；同一刷新操作不能重复触发。
4. 恢复“正常”，开启“下次刷新失败”，点击页面刷新：等待后出现一处局部错误，旧列表/图表保留。点击重试恢复，原 tab、窗口和筛选选择不被重置。
5. 选择“确认无数据”：显示真实空态；与搜索/筛选无结果区分。

共用显示与键盘检查：

- [ ] 浅色、深色主题下状态、图例及数值可读。
- [ ] 390 / 768 / 1440px 下无页面横向溢出；宽告警表允许在其内容区域内横向滚动。
- [ ] 窄屏通过筛选条自身滚动或键盘取得所有筛选项，不能只看到前几项而无法操作后续项。
- [ ] Tab / Enter / 空格可触发按钮、菜单和 tab；方向键在图表中不造成文档翻页。
- [ ] 详情、提供商、分析和移动导航关闭后，焦点合理返回触发按钮。
- [ ] 减少动态效果模式下仍能完成操作和取得图中数据。

这些页面使用示例数据。组织切换演示更改导航身份，不执行其他组织的数据查询；全局搜索弹层仍为原有占位入口。AI 分析、处置、静音和环境详情均为明确标记的本地演示，不代表生产后端或 AI 服务已接入。
