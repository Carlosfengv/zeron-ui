## 基础组件

拟在 Charts 分类增加 `/docs/components/mini-chart`，配套 `@zeron/ui/mini-chart` 和 `npx zeron-ui add mini-chart`。组件接受业务数据，可单独嵌入表格、资源详情或 `Card`。KPI 数值和状态可由 `MetricCard` 承载。通过现有图表 token、数值格式和数据表衔接 Zeron，优先在现有图元上实现紧凑布局。 [Charts 目录](../manifest.ts) [Chart 基础能力](../agent-guides/components/chart.md) [MetricCard](../agent-guides/components/metric-card.md)

| 绘图能力 | 基础形态 | 实施路径 |
| --- | --- | --- |
| 折线与面积 | 单／多序列、阶梯、叠层面积、参考线／区间、末值、预测尾段 | 复用 `LineChart`、`AreaChart` 和 `chart-core`。批大小或并发档位采用数值比例尺，时间序列采用真实时间比例尺。 |
| 柱形与直方图 | 横向、纵向、分组、堆叠、正负柱、时间桶和等宽数值桶 | 复用 `BarChart` 及其选中态和取色能力。分桶由调用方提供，详情读取原始桶区间与计数。 |
| 饼、圆环与弧 | 扇区占比、单环进度、同心多环、并排环、半环和点弧 | 复用 `PieChart`、`DonutSummary` 和 `RingChart`，补齐离散点弧及圆角矩形进度轨。 |
| 进度与标尺 | 分段条、连续计量、分档刻度、当前游标、目标区间 | 复用 `SegmentedBar` 的容量语义，补齐带域、区间和目标标记的紧凑标尺。 |
| 热图与点阵 | 日期×小时、实体×时间、高低强度、离散状态和分片阵列 | 复用 `HeatmapChart` 和连续色阶。紧凑点阵用标签与形态区分零值、未上报和告警。 |
| 时间轨 | 等时桶状态、单轨区间、当前时间和事件标记 | 沿用 `StatusOverview` 和 `TimeWindowTimeline` 的数据语义，为卡片提供单轨布局。 |
| 区间柱与瀑布 | 低高值区间、带首末值的蜡烛式区间、正负增量和合计 | 补齐共享区间柱绘图，范围由真实端点决定。瀑布图基于业务提供的起止值和合计。 |
| 散点 | 两个连续变量、已知分组、逐点查看 | 补齐数值轴散点，与数值折线共用比例尺及读数方式。 |
| 漏斗 | 同一批次的阶段通过数、相邻阶段差值 | 复用 `FunnelChart`，提供紧凑标签和逐阶段读数。 |

用各图形的类型表达数据。时间序列接收毫秒时间戳、稳定的系列 ID 和可空观测值。容量图接收实测用量与上限，组成图接收分项及可选总量。阈值、统计窗口、单位及显示时区由调用方明确传入，同列对照同一指标时使用统一量程。单点显示标记，空数据给出可读状态，零值保留，缺口断开。超额图形按可用空间展示，读数保留真实用量与上限。 `MetricCard` 的三种旧图、24 个有效样本门槛和整卡交互纳入兼容验收。 [图表原语](../agent-guides/components/chart-primitives.md) [圆环](../agent-guides/components/ring-chart.md) [时间轨](../agent-guides/components/time-window-timeline.md)

## 设计和交互标准

- **紧凑尺寸。** 行内趋势以 64–112 × 24–32 px 为目标，普通卡片图高 56–88 px，点阵和时间轨按实际标签高度展开。主值对齐，时间窗与参考值就近显示。紧凑布局优先减少网格和刻度，关键数值与阈值由标签和详情承载。
- **主题与语义。** 主序列用 `--chart-1`，普通比较系列固定映射至 `--chart-1` 至 `--chart-5`，未知和空闲用中性状态，告警按已有状态映射呈现。阈值线、图案或文字提供颜色以外的线索。覆盖浅色、深色和窄卡片。 [Zeron 语义令牌](../../SEMANTIC-TOKENS.md)
- **等价读数。** 静态图提供名称与可读摘要。交互图通过悬停、轻触、方向键查看同一个数据点或时间桶，Escape 清除，键盘或数据表可获得完整标签与数值。整卡有主操作时，图采用静态模式或独立详情入口。
- **真实状态。** 示例提供确定性数据、时间窗和单位。覆盖加载、空、缺口、全零、超额和过期。预测与实测采用不同线型并明确标记；趋势、环和分段条上的数值与 Tooltip 一致。
- **图册体验。** 每例提供实时预览和可复制的完整 TSX。预览支持主题、普通系列换色、速度和重播，告警和未知保持语义色。60 例各录制一份默认主题、1× 速度的 GIF 和 MP4，图册提供成套下载。业务实例默认直接显示数据，遵循 `prefers-reduced-motion`，密集列表中的静态图无需逐图启动动画。 [Quix Studio Finance Charts](https://www.quixstudio.net/free/components#charts) [Zeron ComponentPreview](../components/content/ComponentPreview.tsx)

## 实施与验收

1. **验证基础组件。** 先跑通 12 个样例 `03`、`04`、`06`、`07`、`09`、`20`、`21`、`26`、`34`、`51`、`54`、`57`，覆盖趋势、面积、柱、分布、配额、波动区间和时间轨。测试独立渲染、窄卡片及同页多实例。用 GPU 温度、首 Token 延迟、多云费用和维护窗口校准卡片布局。
2. **完成 60 例和双语文档。** 让图册、示例数据和源码预览来自同一份示例配置。将典型样例嵌入表格单元格、KPI 卡片与运维概览三个预览，使用现有 Project Monitor、AI Gateway Overview 和 Local Models 的指标口径组织场景。 [Project Monitor](../agent-guides/blocks/project-monitor-01.md) [AI Gateway Overview](../agent-guides/blocks/ai-gateway-overview-01.md) [Local Models](../agent-guides/blocks/local-models-01.md)
3. **验证数量、体验和安装。** 核对 `01–60` 的锚点、预览、可运行源码和样例数据。以约 320 px 的窄卡片、密集表格和桌面图册检查布局、主题、键盘、触控及长标签。验证动态数据更新、真实时间间距、空值、超额、SVG 实例隔离和 100 行静态小图，无持续动画。运行类型检查、图表及 MetricCard 的相关回归，并通过 Registry 检查和干净消费项目安装验证导出与依赖。 [组件文档规范](../../component-documentation-guidelines.md)
